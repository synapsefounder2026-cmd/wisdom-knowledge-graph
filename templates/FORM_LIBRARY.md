# Wisdom Assessment Form Library (Vibe Edition)

Inspired by the "Goldmine for Vibecoders", this library contains UI components and prompts designed for the Wisdom ecosystem.

## 🌿 The Mother Earth Vibe
All components should use the following style prompt prefix:
`"Earthy minimalist design, soft natural lighting, terracotta and sage green palette, premium organic textures, Bento grid layout, high-end typography, mindful aesthetic."`

---

## 🏛️ Component Categories

### 1. Lead Capture & Onboarding
**Description**: High-conversion forms for new users.
- **Component**: Hero with Inline Form
- **Prompt**: `Design a hero section for a 'Knowledge Factory' course. Soft sand background, sage green primary button. Inline form for email and name. Minimalist, premium feel.`
- **Department**: Growth & Marketing

### 2. Wisdom Assessment Forms
**Description**: Forms for evaluating knowledge or progress.
- **Component**: Multi-step Progress Assessment
- **Prompt**: `A multi-step form with organic progress bars (leaf-shaped). Smooth transitions. Questions about goals and development. Mindful vibe.`
- **Department**: Wellness & Inspiration

### 3. Agent Interaction Center
**Description**: Chat-like forms to prompt the specialized agents.
- **Component**: Glassmorphic Command Input
- **Prompt**: `A floating command input box with a subtle animation. Transparent background with high-quality blur. Premium labeling on the placeholder.`
- **Department**: Operations

---

## 💎 Features of this Library
- **Multiple Categories**: Organized by functional departments.
- **Variations**: Each component has "Organic" vs "Industrial" variations.
- **Prompt + UI**: Ready-to-use prompts for AI-driven design iteration.
- **Fast Building**: Copy-paste prompts to iterate on Wisdom UI/UX.
